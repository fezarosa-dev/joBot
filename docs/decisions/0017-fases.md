# 0017. Fases do projeto

- **Status:** aceita
- **Data:** 2026-11-13

## Contexto

O projeto é grande. Ir por fases deixa cada entrega testada antes da próxima. Hoje o projeto está em desenvolvimento e ainda não tem código: nenhuma fase está pronta.

## Decisão

- Fase 1, Base: núcleo comum, fontes públicas, banco, painel e agenda. Os detalhes ficam para o desenho da fase 1. Status: em desenho.
- Fase 2, Navegador com login: Chrome visível, mapeamento dos sites e tratamento de CAPTCHA. Status: planejada.
- Fase 3, IA local: pacote offline (llama-server + Qwen). Status: planejada.
- Fase 4, Extensão do navegador. Status: planejada.
- Fase 5, Áudio e Gmail. Status: planejada.
- Fase 6, Treino. Status: planejada.
- Fase 7, Versão GitHub Pages. Status: planejada.
- Fase 8, Publicação: instaladores, README com selos, revisão de segurança e versão em inglês do README. Status: planejada.

## Consequências

- Cada fase só começa depois que a anterior passa nos testes.
