# ⌨️ Keyboard shortcuts

**Everything the dashboard does with the mouse can also be done from the keyboard.**

---

On a Mac, a shortcut uses the ⌘ (Command) key. On Windows and Linux, the same shortcut uses the Ctrl key. ⇧ and Shift are the same key.

## 🧭 On any screen

| On a Mac | Windows and Linux | What it does |
|---|---|---|
| ⌘K | Ctrl+K | Opens and closes the command palette. |
| ⌘, | Ctrl+, | Goes to Settings, in the last group you opened. |
| ⌘? | Ctrl+? | Opens this help (the joBot wiki) in a new tab. |
| Esc or ⌘. | Esc or Ctrl+. | Closes the palette, menu, alert or form window that is open. |
| / | / | Moves the cursor to the search at the top. Only works outside a text field. |

The command palette has a button in the top bar, for anyone who prefers the mouse. In it you type part of a name (accents do not matter), use ↑ and ↓ to choose and Return to run. It only gathers things that already exist in the dashboard: going to each screen, searching now, quitting, and changing theme, language and text size.

> [!NOTE]
> In some browsers, such as Firefox, and Chrome on Windows and Linux, Ctrl+K usually focuses the browser's own search. While the focus is inside the page, joBot keeps the shortcut. If it does not work for you, use the palette button.

## 🗂️ In the job list

| Keys | What it does |
|---|---|
| ↑ and ↓, or K and J | Move to the job above and the job below. J and K only work outside a text field. |
| Home and End | Go to the first and the last job in the list. |
| Return | Opens the job. |
| Menu key or Shift+F10 | Opens the job's menu (open, open on the site, save, hide, copy link). |

Right-clicking opens the same menu. Inside it, ↑ and ↓, Home and End move, and typing a letter jumps to the next item that starts with it. Esc closes the menu and returns the focus to the job. The Searches, Companies, Suggested and Sites lists have the same context menu (menu key or Shift+F10).

## ↩️ Undo and Redo

When you hide a job, discard a suggestion or remove a company, a bar with an **Undo** button appears. The shortcuts press that button while the bar is on screen.

| On a Mac | Windows and Linux | What it does |
|---|---|---|
| ⌘Z | Ctrl+Z | Undoes the last action in the bar. |
| ⇧⌘Z | Ctrl+Shift+Z | Redoes what you just undid. |

Inside a text field, ⌘Z stays with the browser and undoes typing. With no bar on screen, the shortcut does nothing. The bar keeps only the last action.

## 🙅 What the dashboard does not take

⌘F (find on the page) and ⌘A (select all) stay with the browser. joBot also does not use ⌘R, ⌘N, ⌘W, ⌘T, ⌘Q or ⌘L.
