# 💛 Support the project

**joBot is free. Here is how to help the project, with or without money.**

---

## 🙌 Why support it

A single person maintains joBot. Job sites change without notice, and keeping the collectors working takes effort.
Every bit of support helps the project keep going and reach more people.

> [!IMPORTANT]
> **joBot only accepts donations** ([ADR 0020](https://github.com/fezarosa-dev/joBot/blob/main/docs/decisions/0020-apoio-financeiro.md), Portuguese only).
> - Everything stays **free**, for everyone.
> - **No ads**, **no affiliate links** and **no tracking**.
> - Donating **does not change the order of the jobs** and gives no one an advantage.

## 🤝 Help without money

- ⭐ **Star** the [repository](https://github.com/fezarosa-dev/joBot). It helps people find the project.
- 📣 **Spread the word** to people looking for a job.
- 🌎 **Suggest a new job source** with the [source form](https://github.com/fezarosa-dev/joBot/issues/new?template=fonte.yml).
- 🐞 **Report when something breaks**, including a source that stopped working, with the [bug form](https://github.com/fezarosa-dev/joBot/issues/new?template=bug.yml).
- 💡 **Suggest an idea** with the [feature request form](https://github.com/fezarosa-dev/joBot/issues/new?template=sugestao.yml).
- 🙋 **Answer other people's questions** in the [question issues](https://github.com/fezarosa-dev/joBot/issues?q=label%3Aquestion).
- 📝 **Improve this wiki** with a PR in the [`wiki/`](https://github.com/fezarosa-dev/joBot/tree/main/wiki) folder.
- 🧑‍💻 **Contribute code** following the [contribution guide](https://github.com/fezarosa-dev/joBot/blob/main/.github/CONTRIBUTING.en.md). Code PRs are accepted after the release (phase 8).
